Sperm Morphological Quality · Mask R-CNN

Open Source

Mask R-CNN head segmentation and good / bad morphology classification.

Check filesCheck files · Local · Python

What it does · 01

Trained on 1,300 images (Kaggle Sperm Morphological Quality + Mendeley) with ResNet-101 via PixelLib; best mAP 0.89. It is a binary head-quality score, not full WHO-6 (Kruger) morphology — use as a pre-screen.

  • ▸Head mask and class
  • ▸Inference on images and video

Input requirements

  • •Stained (Diff-Quik, Papanicolaou) ×100 crops or fields

How to use

  1. 1Install compatible PixelLib and TensorFlow.
  2. 2Download weights from the repo.
  3. 3Run the inference notebook on your images.

If the tool runs locally only

Needs: Python 3.7–3.9 · TensorFlow 2.x · Jupyter

git clone https://github.com/Kimchi21/Sperm-Morphological-Quality-ImageSegmentation
pip install pixellib tensorflow jupyter
jupyter notebook

Limitations and common mistakes

  • !Two classes only; does not replace strict-criteria assessment.
  • !Sensitive to stain and magnification.
