DiffDock

Open Source
Local · Pythondiffusion dockingblind docking

Diffusion-based blind docking: ligand pose without a predefined pocket.

DockCheck files · Local · Python

What it does · 06

DiffDock generates ligand poses over the whole protein surface and ranks them by confidence. Handy when the pocket is unknown.

  • ▸No box needed

Input requirements

  • •Protein PDB and SMILES

How to use

  1. 1Create the env per README.
  2. 2Run inference on your protein and ligand.

If the tool runs locally only

Needs: Python 3.9 · PyTorch · GPU

git clone https://github.com/gcorso/DiffDock && cd DiffDock
conda env create -f environment.yml

Limitations and common mistakes

  • !Re-check poses with physics-based methods.
