What it does · 05

HistoGPT reads whole-slide features and writes a pathologist-style description. Trained on dermatopathology; supports questions about the slide.

  • ▸Text slide description
  • ▸Questions about the slide

Input requirements

  • •Skin H&E WSI

How to use

  1. 1Install and download weights from Hugging Face.
  2. 2Extract slide features and generate a report.

If the tool runs locally only

Needs: Python 3.10 · GPU ≥ 24 ГБ

git clone https://github.com/marrlab/HistoGPT && cd HistoGPT
pip install -e .

  • !Can hallucinate: a pathologist checks every statement.
