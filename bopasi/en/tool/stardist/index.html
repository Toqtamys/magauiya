StarDist

Open Source
Local · Pythonnucleus detectionstar-convexFijiQuPath

Nucleus detection with star-convex polygons; plugins for Fiji, QuPath and napari.

Check filesCheck files · Local · Python

What it does

StarDist is a fast, accurate nucleus detector with ready models 2D_versatile_he for H&E and 2D_versatile_fluo for fluorescence. Works in QuPath with no coding.

  • ▸H&E and fluorescence models
  • ▸Fiji/QuPath/napari plugins

Input requirements

  • •H&E/DAPI tiles or fields, ×20–×40

How to use

  1. 1pip install stardist tensorflow.
  2. 2Load 2D_versatile_he and call predict_instances.
  3. 3Or in QuPath: Extensions → StarDist.

If the tool runs locally only

Needs: Python 3.9+ · TensorFlow

pip install stardist tensorflow
python -c "from stardist.models import StarDist2D; m = StarDist2D.from_pretrained('2D_versatile_he')"

Limitations and common mistakes

  • !No cell-type classification.

What you get

  • →Nucleus masks and polygons
