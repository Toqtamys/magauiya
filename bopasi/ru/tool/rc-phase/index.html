Что умеет

На ICSI-станциях ооциты и эмбрионы снимают в рельефном (RC/Хоффмановском) контрасте, а многие модели и атласы обучены на фазовом. Инструмент использует физическую модель изображения, а не «перекраску»: RC-снимок приблизительно равен производной оптической толщины вдоль направления тени, а фазовый контраст — самой оптической толщине с характерным светлым ореолом. RC → ФК: определяем угол тени по анизотропии спектра, интегрируем вдоль него в частотной области с регуляризацией и рисуем фазовый контраст с ореолом. ФК → RC: восстанавливаем оптическую толщину, снимая ореол деконволюцией, и берём направленную производную — получается рельеф с «тенью». Для фотореалистичного перевода конкретного микроскопа можно дообучить CycleGAN на своих снимках.

  • ▸Оба направления: RC → фазовый контраст и фазовый контраст → RC
  • ▸Автоопределение угла тени и знака рельефа
  • ▸Ползунки: угол, сила, размер ореола, регуляризация, позитивный/негативный ФК
  • ▸Шторка «до/после», пакетная обработка, скачивание PNG

Требования к входным данным

  • •Фото JPG/PNG/BMP/WebP ооцита, зиготы, эмбриона, сперматозоидов или клеток
  • •Любое увеличение; объект в фокусе, фон без пересвета
  • •Без надписей и стрелок поверх объекта (их лучше обрезать)

Как пользоваться

  1. 1Нажмите «Создать» — откроется конвертер.
  2. 2Перетащите снимок и выберите направление: RC → ФК или ФК → RC.
  3. 3Угол тени определяется автоматически; если ореол лёг не с той стороны — нажмите «Инвертировать рельеф».
  4. 4Подстройте силу и ореол, сравните шторкой «до/после».
  5. 5Скачайте PNG. Для серии загрузите несколько файлов — параметры применятся ко всем.

Если инструмент работает только локально

Нужно: Python 3.8+ · PyTorch · GPU · 200+ снимков каждого типа

git clone https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix
cd pytorch-CycleGAN-and-pix2pix && pip install -r requirements.txt
# datasets/rc2pc/trainA = RC, trainB = phase contrast
python train.py --dataroot ./datasets/rc2pc --name rc2pc --model cycle_gan
python test.py --dataroot ./datasets/rc2pc --name rc2pc --model cycle_gan
  • ↳Браузерная версия не требует установки. Локально — только если нужен ИИ-перевод под конкретный микроскоп.

Ограничения и типичные ошибки

  • !Модель приближённая: тонкие структуры (полярное тельце, веретено) восстанавливаются, но абсолютная оптическая толщина — нет.
  • !Неравномерное освещение даёт полосы вдоль направления тени — уменьшите силу или увеличьте регуляризацию.
  • !Не используйте результат для измерений и клинических решений — только для визуализации и подготовки данных.

  • →Найденный угол тени — полезен, чтобы понять ориентацию RC-модулятора
