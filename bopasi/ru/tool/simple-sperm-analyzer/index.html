simple-sperm-analyzer

Open Source
Локально · PythonmotilityOpenCVbatch

Пакетный анализ подвижности на OpenCV: детекция, трекинг, VCL/VSL/VAP.

Проверить файлыПроверить файлы · Локально · Python

Что умеет

Лёгкий конвейер без нейросетей: учитывает движение для детекции, связывает объекты в треки и считает скорости. Параметры задаются JSON-файлом, что удобно для серий и воспроизводимости. Подходит и для спермы животных (в примере — данио).

  • ▸Пакетная обработка папок
  • ▸Видео-оверлей с треками
  • ▸Параметры в JSON

Требования к входным данным

  • •AVI/MP4: белые головки на чёрном фоне (при необходимости инвертируйте в Fiji)
  • •Вычитание фона и контраст — заранее в ImageJ/Fiji

Как пользоваться

  1. 1Подготовьте видео в Fiji: Invert → Subtract Background → Brightness/Contrast.
  2. 2Установите uv и зависимости.
  3. 3Скопируйте пример JSON параметров и задайте масштаб и частоту.
  4. 4Запустите main.py на папке с видео.

Если инструмент работает только локально

Нужно: Python 3.12+ · uv

pip install uv
git clone https://github.com/elemeng/simple-sperm-analyzer
cd simple-sperm-analyzer && uv sync
uv run main.py --help

Ограничения и типичные ошибки

  • !Требует ручной предобработки контраста.
  • !Нет классов ВОЗ «из коробки» — пороги задаёте сами.

Что вы получите на выходе

  • →CSV по трекам и сводки VCL/VSL/VAP, видео с разметкой
