Деформируемый трансформер для классификации стадий развития эмбриона по time-lapse.

Проверить файлыПроверить файлы · Статья + код

Что умеет

Модель с совместным кодированием-декодированием предсказывает стадию (1-клеточный, 2, 3, 4+ клетки, морула, бластоциста) для каждого кадра time-lapse с учётом монотонности развития. Код опубликован авторами вместе со статьёй — ищите ссылку на странице arXiv/WACV.

  • ▸Покадровая стадия
  • ▸Учёт временной согласованности

Требования к входным данным

  • •Видео time-lapse одного эмбриона

Как пользоваться

  1. 1Откройте статью и найдите официальный код.
  2. 2Подготовьте кадры по формату авторов.
  3. 3Запустите инференс на GPU.
