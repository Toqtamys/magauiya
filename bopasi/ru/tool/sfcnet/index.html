SFCNet

Open Source
Локально · Pythonsegmentationdetectionmotile spermdeep learning

Нейросеть с корреляцией признаков для сегментации и детекции подвижных сперматозоидов без окраски.

Проверить файлыПроверить файлы · Локально · Python

Что умеет

SFCNet — официальная реализация статьи в IEEE Transactions on Automation Science and Engineering (2024). Сеть выделяет головку и хвост живых неокрашенных сперматозоидов и подходит для неинвазивного отбора (например, перед ICSI).

  • ▸Семантическая сегментация частей сперматозоида
  • ▸Детекция подвижных клеток
  • ▸Скрипты обучения и оценки

Требования к входным данным

  • •Кадры видео высокого увеличения (×40–×100), без окраски
  • •Набор данных в формате из readme/DATA.md

Как пользоваться

  1. 1Установите по readme/INSTALL.md.
  2. 2Подготовьте данные по DATA.md.
  3. 3Запустите shell/segmentation.sh или shell/detection.sh.

Если инструмент работает только локально

Нужно: Python 3 · PyTorch · GPU

git clone https://github.com/anthonyweidai/SFCNet
cd SFCNet
bash shell/segmentation.sh

Ограничения и типичные ошибки

  • !Исследовательский код: нужны GPU и навыки Python.
  • !Веса и данные — по ссылкам в репозитории.
