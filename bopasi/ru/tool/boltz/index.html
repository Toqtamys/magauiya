Open Source
Локально · Pythonco-foldingaffinityAlphaFold3-like

Открытая со-фолдинговая модель уровня AlphaFold3: комплекс белок–лиганд и оценка аффинности.

DockПроверить файлы · Локально · Python

Что умеет · 06

По последовательности белка и SMILES лиганда Boltz-2 строит 3D-комплекс и оценивает аффинность — альтернатива докингу без кристаллической структуры.

  • ▸Белок, нуклеиновые кислоты, лиганды

Требования к входным данным

  • •YAML с последовательностью и SMILES

Как пользоваться

  1. 1pip install boltz.
  2. 2Запустите предсказание на входном YAML.

Если инструмент работает только локально

Нужно: Python 3.10+ · GPU NVIDIA ≥ 16 ГБ

pip install boltz
boltz predict input.yaml --use_msa_server

Ограничения и типичные ошибки

  • !Нужна GPU; аффинность — оценка.

Что вы получите на выходе

  • →mmCIF комплекса, уверенность, аффинность
