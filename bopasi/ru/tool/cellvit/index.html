CellViT

Open Source
Локально · Pythonvision transformernucleusPanNukeSAM

Vision Transformer (на основе SAM) для сегментации и классификации ядер на целых слайдах.

Проверить файлыПроверить файлы · Локально · Python

Что умеет

CellViT использует энкодер ViT, предобученный на гистологии или SAM, и декодер в стиле HoVer-Net. Обгоняет HoVer-Net на PanNuke и обрабатывает гигапиксельные WSI с экспортом в GeoJSON для QuPath.

  • ▸WSI-инференс с GeoJSON
  • ▸5 классов PanNuke

Требования к входным данным

  • •WSI SVS/NDPI/TIFF с известным mpp (0,25 или 0,5)

Как пользоваться

  1. 1Установите окружение и скачайте чекпойнт CellViT-SAM-H.
  2. 2Предобработайте слайд (нарезка патчей) скриптом preprocessing.
  3. 3Запустите cell_detection.py, откройте GeoJSON в QuPath.

Если инструмент работает только локально

Нужно: Python 3.9 · PyTorch · GPU ≥ 16 ГБ

git clone https://github.com/TIO-IKIM/CellViT && cd CellViT
conda env create -f environment.yml
  • ↳Python-окружение (conda / venv) и, желательно, GPU NVIDIA с CUDA

Ограничения и типичные ошибки

  • !Тяжёлая модель: нужна мощная GPU.
  • !Лицензии компонентов различаются — читайте LICENSE.
