PathML

Open Source
Локально · PythonpipelinemultiplexCODEXHoVer-Net

Конвейеры предобработки и анализа для H&E, ИГХ и мультиплексной иммунофлуоресценции.

Проверить файлыПроверить файлы · Локально · Python

Что умеет · 05

PathML объединяет чтение слайдов, нормализацию, сегментацию ядер (в т.ч. Mesmer для мультиплекса) и подготовку датасетов в воспроизводимые конвейеры.

  • ▸Мультиплекс (CODEX, Vectra)
  • ▸Готовые конвейеры

Требования к входным данным

  • •WSI H&E/ИГХ или мультиплексные TIFF

Как пользоваться

  1. 1Установите через conda (OpenSlide, Java).
  2. 2Соберите Pipeline из трансформаций и запустите.

Если инструмент работает только локально

Нужно: Python 3.9 · OpenSlide · OpenJDK

conda create -n pathml python=3.9 && conda activate pathml
conda install -c conda-forge openslide openjdk
pip install pathml

Ограничения и типичные ошибки

  • !Сложная установка зависимостей.

Что вы получите на выходе

  • →Тайлы, маски, табличные признаки (h5path)
