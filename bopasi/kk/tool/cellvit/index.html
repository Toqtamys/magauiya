CellViT

Open Source
Жергілікті · Pythonvision transformernucleusPanNukeSAM

Тұтас слайдтарда ядроларды сегментациялау және жіктеуге арналған Vision Transformer (SAM негізінде).

Файлдарды тексеруФайлдарды тексеру · Жергілікті · Python

Не істей алады · 03

CellViT гистологияда немесе SAM-да алдын ала оқытылған ViT энкодерін және HoVer-Net стиліндегі декодерді пайдаланады. PanNuke-те HoVer-Net-тен озады және QuPath үшін GeoJSON экспортымен гигапиксельді WSI өңдейді.

  • ▸GeoJSON-мен WSI-инференс
  • ▸5 PanNuke класы

Кіріс деректерге талаптар

  • •Белгілі mpp (0,25 немесе 0,5) бар WSI SVS/NDPI/TIFF

Қалай пайдалану керек

  1. 1Ортаны орнатып, CellViT-SAM-H чекпойнтын жүктеңіз.
  2. 2Слайдты preprocessing скриптімен алдын ала өңдеңіз (патчтарға бөлу).
  3. 3cell_detection.py іске қосып, GeoJSON-ды QuPath-та ашыңыз.

Құрал тек жергілікті жұмыс істесе

Қажет: Python 3.9 · PyTorch · GPU ≥ 16 ГБ

git clone https://github.com/TIO-IKIM/CellViT && cd CellViT
conda env create -f environment.yml
  • ↳Python ортасы (conda / venv) және мүмкіндігінше CUDA бар NVIDIA GPU
