CASA үшін Python жинағы: бейне жүктеу, детекция (YOLO және т.б.), SORT/DeepSORT/JPDAF трекингі, қозғалғыштық параметрлері.

Файлдарды тексеруФайлдарды тексеру · Жергілікті · Python

Не істей алады · 01

pycasa бүкіл CASA конвейерін бір Casa нысаны айналасында құрады: кадрларды алдын ала өңдеу, бірнеше детектор, трекерлер және кинематиканы есептеу, сондай-ақ эталондық белгілеумен салыстыру. Зерттеуге ыңғайлы: детектор мен трекерді ауыстырып, нәтижені салыстыруға болады.

  • ▸Детекторлар: moving-cells, digital washing, Urbano, YOLO v5
  • ▸SORT, DeepSORT, JPDAF трекингі
  • ▸Белгілеуге қарсы бағалау және визуализация

Кіріс деректерге талаптар

  • •Фазалық контраст немесе жарық өріс бейнесі, ×10–×20, 30–60 кадр/с
  • •Жылдамдықтарды есептеу үшін белгілі мкм/пикс. масштабы

Қалай пайдалану керек

  1. 1Бейнені жүктеу аймағында тексеріңіз.
  2. 2Пакетті pip арқылы орнатыңыз (төмендегі команда).
  3. 3Алдымен кірістірілген деректерде мысалды іске қосыңыз, содан кейін өз бейнеңізді жүктеңіз.
  4. 4Детектор мен трекерді таңдап, қозғалғыштық есебін шақырыңыз.

Құрал тек жергілікті жұмыс істесе

Қажет: Python 3.9+

pip install "pycasa[io,yolo] @ git+https://github.com/DFL-KamLab/pycasa.git"
python -c "import pycasa as pc; s = pc.io.load_default_data(); s.preprocessing.binarization.otsu(); s.detection.yolo(); s.info()"
