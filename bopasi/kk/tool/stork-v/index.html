STORK бейне нұсқасы: эмбрионды бүкіл time-lapse тізбегі бойынша бағалау (BELA желісі).

Файлдарды тексеруФайлдарды тексеру · Жергілікті · Docker

Не істей алады

STORK-V бір суретті емес, time-lapse инкубаторының кадрлар тізбегін талдайды. BELA моделімен (Weill Cornell) байланысты, ол 96–112 сағ дейінгі бейне бойынша бластоциста сапасы мен плоидтылықты болжайды.

  • ▸Веб-интерфейсі бар Docker қызметі
  • ▸Кадрлар ZIP мұрағатын талдау

Кіріс деректерге талаптар

  • •Бір эмбрионның кадрлары бар ZIP (EmbryoScope, барлық сағаттар, бір фокалдық жазықтық)

Қалай пайдалану керек

  1. 1Модельдерді src/stork_v/models қалтасына салыңыз.
  2. 2docker run … -p 8080:80 stork-v контейнерін іске қосыңыз.
  3. 3localhost:8080 ашып, ZIP жүктеңіз.

Құрал тек жергілікті жұмыс істесе

Қажет: Docker · модели (по запросу у авторов)

git clone https://github.com/eipm/stork-v && cd stork-v
docker build -t stork-v .
docker run -v $PWD/models:/stork-v/stork_v/models -v $PWD/data:/stork-v/data -e USERS_DICT="{'user1': 'stork'}" -p 8080:80 stork-v
