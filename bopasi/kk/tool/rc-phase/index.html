Не істей алады

ICSI станцияларында ооциттер мен эмбриондар рельефтік (RC/Хоффман) контрастта түсіріледі, ал көптеген модельдер мен атластар фазалық контрастта оқытылған. Құрал «қайта бояуды» емес, кескіннің физикалық моделін пайдаланады: RC суреті көлеңке бағыты бойынша оптикалық қалыңдықтың туындысына шамамен тең, ал фазалық контраст — оптикалық қалыңдықтың өзі, тән ашық ореолымен. RC → ФК: спектр анизотропиясы бойынша көлеңке бұрышын анықтаймыз, жиілік аймағында регуляризациямен сол бағытта интегралдаймыз және ореолы бар фазалық контрастты саламыз. ФК → RC: ореолды деконволюциямен алып, оптикалық қалыңдықты қалпына келтіреміз де, бағытталған туындыны аламыз — «көлеңкесі» бар рельеф шығады. Нақты микроскопты фотошынайы аудару үшін CycleGAN-ды өз суреттеріңізде оқытуға болады.

  • ▸Екі бағыт: RC → фазалық контраст және фазалық контраст → RC
  • ▸Көлеңке бұрышы мен рельеф таңбасын автоматты анықтау
  • ▸Жүгірткілер: бұрыш, күш, ореол өлшемі, регуляризация, позитивті/негативті ФК
  • ▸«Дейін/кейін» шторкасы, пакеттік өңдеу, PNG жүктеу

Кіріс деректерге талаптар

  • •Ооцит, зигота, эмбрион, сперматозоид немесе жасушалар фотосы JPG/PNG/BMP/WebP
  • •Кез келген үлкейту; нысан фокуста, фон артық жарықсыз
  • •Нысан үстінде жазулар мен көрсеткіштерсіз (оларды кесіп тастаған жөн)

Қалай пайдалану керек

  1. 1«Жасау» батырмасын басыңыз — түрлендіргіш ашылады.
  2. 2Суретті сүйреп, бағытты таңдаңыз: RC → ФК немесе ФК → RC.
  3. 3Көлеңке бұрышы автоматты анықталады; ореол дұрыс емес жағына түссе — «Рельефті инверттеу» батырмасын басыңыз.
  4. 4Күш пен ореолды реттеп, «дейін/кейін» шторкасымен салыстырыңыз.
  5. 5PNG жүктеңіз. Серия үшін бірнеше файл жүктеңіз — параметрлер барлығына қолданылады.

Құрал тек жергілікті жұмыс істесе

Қажет: Python 3.8+ · PyTorch · GPU · 200+ снимков каждого типа

git clone https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix
cd pytorch-CycleGAN-and-pix2pix && pip install -r requirements.txt
# datasets/rc2pc/trainA = RC, trainB = phase contrast
python train.py --dataroot ./datasets/rc2pc --name rc2pc --model cycle_gan
python test.py --dataroot ./datasets/rc2pc --name rc2pc --model cycle_gan
