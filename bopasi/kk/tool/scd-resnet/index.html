scd-resnet · SCD / Halo-тест

Open Source
Жергілікті · PythonDNA fragmentationDFISCDHaloCNN

Хроматин дисперсиясы тестін (SCD/Halo) автоматты талдау: ядроларды табу, гало өлшеу, DFI есептеу.

Файлдарды тексеруФайлдарды тексеру · Жергілікті · Python

Не істей алады

SCD-тестте агарозадағы сперматозоидтарды қышқылмен және лизистік ерітіндімен өңдейді. Зақымданбаған ДНҚ ядро айналасында хроматин ілмектерінен үлкен немесе орташа «гало» түзеді, фрагменттелген — кіші гало, галосыз немесе дегенеративті ядро. scd-resnet (ResNet негізіндегі CenterNet-тәрізді желі) әр ядроны табады, ал гаусс кластерлеуі оны гало өлшемі бойынша класқа жатқызады. DFI = (кіші гало + галосыз + дегенеративті) / барлығы × 100%.

  • ▸Толық өріс суретінде ядроларды анықтау (512×512 клиптер)
  • ▸Кластар: үлкен, орташа, кіші гало, галосыз, дегенеративті
  • ▸Қайта оқыту үшін SCD Label белгілеу утилитасы (Windows)

Кіріс деректерге талаптар

  • •×20 объективпен, автоақ балансымен түсірілген SCD-препарат суреттері
  • •Жинақ бойынша бояу (Diff-Quik / Wright / флуоресценттік) — барлық өрістер үшін бірдей
  • •Сығылмаған JPG/PNG/TIFF, 1024×768-ден; бір үлгіге кемінде 500 ядро

Қалай пайдалану керек

  1. 1Суреттерді төмендегі аймаққа жүктеңіз — платформа формат пен ажыратымдылықты тексереді.
  2. 2Ортаны орнатыңыз (Python 3.8, PyTorch 1.7) және репозиторийді клондаңыз.
  3. 3Дайын модель үшін суреттер қалтасын көрсетіп test.py іске қосыңыз; өз зертханаңыз үшін алдымен SCD Label-де 30–50 суретті белгілеп, қайта оқытыңыз (preprocess.py → train.py).
  4. 4Кластар бойынша ядролар санын қосып, DFI есептеңіз.

Құрал тек жергілікті жұмыс істесе

Қажет: Python 3.8 · PyTorch 1.7.1 · GPU (желательно) · Windows для SCD Label

git clone https://github.com/Xornent/scd-resnet
cd scd-resnet
conda create -n scd python=3.8 && conda activate scd
pip install torch==1.7.1 torchvision==0.8.2 numpy opencv-python
python test.py
  • ↳Дайын салмақтар репозиторийде кепілдендірілмеген: олар болмаса, өз белгілеуіңізде оқыту қажет.

Шектеулер мен жиі қателер

  • !Модель ×20 және нақты SCD жинағында оқытылған — басқа жинақтар мен үлкейтулер қайта оқытуды талап етеді.
  • !Қабаттасқан гало мен агароза көпіршіктері — қателердің негізгі көзі.
  • !PyTorch ескі нұсқалары; жаңаларында кодты түзету қажет болуы мүмкін.

Шығуда не аласыз

  • →Әр ядроның координаттары мен гало класы
  • →DFI % = (кіші гало + галосыз + дегенеративті) / барлық ядролар × 100
  • →SCD бағдарлары: ≤ 15–20% — қалыпты, 20–30% — шекаралық, > 30% — жоғары тәуекел (табалдырықтар зертханаға байланысты).
