Әлсіз белгілеу бойынша тұтас слайдтарды жіктеу және ісік аймақтарының жылу карталары.

Файлдарды тексеруФайлдарды тексеру · Жергілікті · Python

Не істей алады

CLAM тек слайд белгісі бойынша оқиды (мысалы, «метастаз бар/жоқ» немесе ісік кіші түрі) және диагностикалық маңызды аймақтарды өзі табады. Назар жылу карталары іс жүзінде пиксельдік белгілеусіз ісік аймақтарының сегментациясын береді.

  • ▸Тінді сегментациялау және патчтарға бөлу
  • ▸Белгілерді шығару (ResNet, UNI, CONCH)
  • ▸Назар жылу карталары

Кіріс деректерге талаптар

  • •Слайд деңгейіндегі белгілері бар WSI жинағы (CSV)

Қалай пайдалану керек

  1. 1create_patches_fea.py — тінді сегментациялау және патчтар.
  2. 2extract_features_fp.py — патч белгілері.
  3. 3main.py — оқыту; create_heatmaps.py — карталар.

Құрал тек жергілікті жұмыс істесе

Қажет: Python 3.10 · PyTorch · OpenSlide · GPU

git clone https://github.com/mahmoodlab/CLAM && cd CLAM
conda env create -f env.yml && conda activate clam_latest
python create_patches_fea.py --source WSI_DIR --save_dir RESULTS --patch_size 256 --seg --patch --stitch
