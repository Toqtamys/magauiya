Блютол-счётчик

Тест фрагментации ДНК сперматозоидов с толуидиновым синим. Загрузите снимки — программа найдёт головки со светлой (акросомальной) частью и разделит их по окраске.

синяя, тёмно-синяя, фиолетовая — фрагментация

Нажмите на клетку, чтобы сменить класс: норма → фрагм. → исключить. Наведите курсор — увидите причину.

Ручная правка

В режиме «+» клик по пустому месту ставит метку для пропущенной клетки. Клик по ручной метке удаляет её.

Порог окраски

Ниже порог оттенка — строже (больше клеток уходит во фрагментированные). Ручные правки не сбрасываются.

Интерпретация

Индекс = фрагмент. / (норма + фрагм.) × 100%. Исключённые объекты в расчёт не входят. Обычно оценивают не менее 200 клеток; сверяйте результат с референсом вашей лаборатории. Автоматическая разметка — подсказка, окончательное решение за специалистом.

Снимков пока нет

Добавьте одно или несколько фото мазка, окрашенного толуидиновым синим. Каждый снимок появится здесь с разметкой: зелёный контур — норма, красный — фрагментация, серый пунктир — исключено.

Снимки обрабатываются только в вашем браузере и никуда не отправляются.
