# Блютол-счётчик

Подсчёт индекса фрагментации ДНК сперматозоидов по снимкам мазков, окрашенных толуидиновым синим.

- **Норма** — светло-голубые и голубые головки.
- **Фрагментация** — синие, тёмно-синие и фиолетовые головки.
- **Учитываются** только головки со светлой (акросомальной) частью.
- **Исключаются** круглые клетки, эпителий, кристаллы, мусор и тени.

Индекс = фрагментированные / (норма + фрагментированные) × 100%.

## Состав

| Файл | Назначение |
| --- | --- |
| `bluetol.html` | Готовое приложение. Откройте двойным щелчком в Chrome, Edge или Firefox. Работает без интернета (кроме шрифтов), снимки никуда не отправляются. |
| `src/core.js` | Алгоритм анализа. Один и тот же код используется в браузере и в Node.js. |
| `src/ui.html` | Интерфейс (исходник для сборки). |
| `build.js` | Собирает `bluetol.html` из `src/`: `node build.js`. |
| `cli.js` | Пакетный анализ из командной строки, вывод в CSV. |

## Работа в браузере

1. Откройте `bluetol.html`.
2. Перетащите снимки в поле «Добавить снимки».
3. Проверьте разметку: зелёный — норма, красный — фрагментация, серый пунктир — исключено.
4. Исправьте ошибки кликом по клетке (норма → фрагм. → исключить). Пропущенные клетки добавляются в режиме «+ норма» / «+ фрагм.».
5. Скопируйте итог кнопкой «Копировать отчёт» или «Копировать CSV».

Ползунок «Оттенок» задаёт границу голубой/синий (по умолчанию 212°). Ползунок «R» задаёт порог тёмных головок (по умолчанию 55).

## Командная строка

```bash
npm install
node cli.js снимки/*.jpg > результат.csv
```

CLI анализирует снимки в полном разрешении, а браузер — уменьшенные холстом до 1300 пикс. Поэтому цифры могут отличаться на 1–3 клетки на снимок.

## Алгоритм (src/core.js)

1. Уменьшение до ширины 1300 пикс.
2. Оценка фона: медиана блоков 16×16, 60-й процентиль в окне 13×13 блоков, билинейная интерполяция.
3. Окраска = фон(R) − R; маска при пороге 14, морфологическое закрытие, заполнение отверстий, открытие.
4. Разделение слипшихся объектов (площадь 1,45–4,5 медианы) последовательной эрозией.
5. Признаки объекта: площадь, вытянутость, доля бледных пикселей, асимметрия окраски, цвет 25% наиболее окрашенных пикселей.
6. Правила исключения: размер, форма, цвет, отсутствие светлой части.
7. Классификация: фрагментация, если оттенок ≥ 212° или R < 55.

Параметры по умолчанию — `DEF` в начале `src/core.js`.

## Ограничения

Пороги подобраны на трёх снимках одного образца и не сверены с ручным подсчётом эксперта. Перед клиническим использованием нужна валидация. Результат программы — вспомогательный; заключение даёт специалист.
